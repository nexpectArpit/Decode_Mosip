# Pinned upstream demo configuration

These configuration and SQL files were copied from the `mosip/inji-certify`
checkout at commit `e54539a89616f64dc90e8f6797db9e66d826d97d`. The source
checkout had local demo fixes to the Certify configuration, SQL seed, Nginx
routes, and Mimoto configuration. They are included here so Compose can run
without a second checkout. The copied files remain under MPL 2.0; see
[`LICENSE`](LICENSE).

The two `data-share-*.properties` files came from the `mosip/inji-web`
checkout at commit `a9f4f829d3070be34ae11649327ea1561e123a2b`.

The private Nginx key and Mimoto PKCS#12 keystore are generated by
`infra/init-certs.sh` into a Docker volume at startup and are not stored here.
The FarmerCredential claim allowlist repair is in
`infra/repair-certify-claims.sql`.
